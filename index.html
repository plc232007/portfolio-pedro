📐 In production

LVM — Virtual Math Lab (IFB)

Problem
A capstone project at IFB needed to replace a static wall of links with something where students manipulate the geometry instead of just reading about it.
Solution
A Next.js lab: students drag the triangle and see the metric relations hold in any position. Exercises are seed-generated, so the numbers change on every attempt. Fermat, an AI assistant, answers questions in the context of the activity without giving away the answer.
Technical decisions
Pure math domain, isolated from the UI. Deterministic generators covered by property-based tests (fast-check). The assistant runs on the server, so the API key never reaches the browser.
Next.js 16 React 19 TypeScript Vitest fast-check LLM

💰 In production

Account Organizer

Problem
The family's finances lived in a spreadsheet, with no separation between each person's data.
Solution
A Next.js app installable as a PWA: expenses and income, bills with due dates, installment purchases and a monthly summary.
Technical decisions
Each user only sees their own data, enforced in the database by Row Level Security (Supabase). Validation with Zod, versioned SQL migrations and a shadcn/ui interface.
Next.js 16 React 19 TypeScript Supabase Zod PWA

⛪ In use

Student Portal — Catechesis IC

Problem
The Christian Initiation of Adults class needed one place, easy to open on a phone, for the schedule, the content of each session, the saints of the week and the prayers.
Solution
An installable PWA with offline navigation: sessions organized by the pillars of the Catechism, saints week by week and prayers in Portuguese and Latin. Aquino, an AI assistant, answers questions about the faith drawing on the class's own material.
Technical decisions
Plain HTML, CSS and JavaScript, no framework or build step. A Service Worker handles the offline cache and YouTube videos load only on click. Aquino runs in a serverless function with Gemini, so the API key never reaches the browser, and the route limits message size.
JavaScript PWA Service Worker Gemini API Serverless LLM
